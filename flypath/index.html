          Export path

          1. Open the app you want to film

            Make its 3D view the same shape as this editor's frame (16:9). Field of view in ArcGIS is measured on the diagonal, so the same shape gives the same framing. Hide or collapse any panels that cover the view.

          2. Paste the player into the browser console

            Press F12, open Console, paste and press Enter. It contains the path and the playback engine, finds the app's SceneView and creates a flypath object. Chrome may ask you to type allow pasting first.

          3. Link the tracks to the app's controls

            Each track moves one slider or switch in the app. Open the panel that holds those controls first, so they are on the page.

              
          
              Check the links any time with flypath.tracks(). Links made by clicking are remembered for that app in this browser.
              • 
        
            • Record
              
          
              
            
              Real time: start your screen recorder, then run this. The camera moves to the first keyframe, waits until the scene there has loaded (up to 10 s), counts down 3 seconds and flies. The console says when the flight has finished. Tip: run flypath.goToStart() while you set up the recorder, so the start is already loaded and play begins almost at once.
              
            
              flypath.play({ delay: 3 })
              
            
              To stop: press Esc on the app page (click the page first if the console has focus), or run flypath.stop() in the console. The camera stays where it is and the app's interface comes back.
              
            
              Frame by frame (smoothest): every frame waits until all tiles and buildings have loaded, then is saved as an image. Chrome asks for a folder to write into.
              
            
              flypath.render({ fps: 30, width: 1920, height: 1080 })
              
            
              Join the frames into a video with ffmpeg:
              
            
              ffmpeg -framerate 30 -i frame_%05d.png -c:v libx264 -pix_fmt yuv420p -crf 16 flypath.mp4
              
          
              • 
        
            • If the view isn't found
              
          
              Apps built with a bundler hide the view object. If you can edit the app, add window.__view = view; after the view is created, or load flypath.js from the Code module tab and call FlyPathPlayer.play(view, path) yourself.
              • 
      
            
    
            
    
            
      
            Renders the path in this editor with your current basemap and layers. Path lines and markers are hidden while rendering. Each frame waits until the scene has finished loading.
            
      
            
        
            
        
            
        
            
        
            —
            
      
            
      
            Resolutions above the frame's on-screen pixel size are upscaled by the SDK. For the sharpest result, make the browser window large or full screen first.
            
      
            
      
            
    
            
    
            
      
            The path as JSON: keyframes in WGS84 longitude/latitude/altitude with heading, tilt and FOV, plus timing and aim settings and your layer list. Open it again here with Open.
            
      
            
      
            Baked cameras are one camera per frame at the timecode frame rate: [t, lon, lat, z, heading, tilt, fov]. Use them in tools that only need a list of cameras.
            
      
    
            
    
            
      
            flypath.js is the same engine this editor uses, as an ES module with no dependencies. It works with ArcGIS Maps SDK for JavaScript 4.x and 5.x SceneViews.

            Copy a camera in the other app
        
            Open its console and run this. It copies the 3D view's camera to the clipboard. It also works while the debugger is paused where view exists.
            
        
            ((v) => copy({ ...v.camera.toJSON(), viewingMode: v.viewingMode }))(typeof view !== "undefined" && view.camera ? view : window.flypath?.view || window.__view || document.querySelector("arcgis-scene, arcgis-map")?.view)
            
        
            Also accepted: name: value lines (longitude, latitude, x, y, z, altitude, heading, tilt, fov), Web Mercator x/y, or 2–6 bare numbers in the inspector's order: longitude, latitude, altitude, field of view, heading, tilt. With a keyframe selected you can also just press Ctrl V anywhere outside a text field.
